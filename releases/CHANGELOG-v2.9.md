# Fusch 2.9 · Android

Aktuelle, separat signierte Android-APK (VersionCode 22, Android 8.0+).

- Kein schwebendes Overlay und keine Dynamic Island mehr.
- Während eines aktiven Standorts oder einer Route zeigt die App nur Status und
  **Stoppen**; andere Aktionen sind bis zum Stop gesperrt.
- Favoriten und Verlauf in übersichtlichen Karten mit Suche/Sortierung,
  Einzelaktionen und Bestätigung vor „Alle löschen“.
- Laufende Routen und Status bleiben bei App-Wechsel und Neustart sichtbar;
  die Android-Dauerbenachrichtigung besitzt weiterhin eine Stop-Aktion.
- Neue Website mit Aufnahmen der tatsächlich in der APK enthaltenen Oberfläche
  (Beispieldaten), interaktiver Online-Karte und aktuellem Release-Status.

## Wichtiger Hinweis für Version 2.5

**Kein Direkt-Update von der bisher über die Website angebotenen 2.5:** Die 2.9
hat eine andere Signatur. Wer 2.5 installiert hat, muss diese App zuerst
deinstallieren; dadurch gehen lokal gespeicherte App-Daten verloren. Die mit
demselben neuen Zertifikat signierten 2.6–2.8 können direkt auf 2.9 aktualisiert
werden. Das bisherige Update-Manifest bleibt absichtlich bei 2.5 / Code 18,
damit alten Installationen keine nicht installierbare APK als Update angeboten
wird.
